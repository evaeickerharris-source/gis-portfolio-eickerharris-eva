Map Overview

This project calculates the Normalized Difference Vegetation Index (NDVI) for the Science Park, Utrecht area to assess vegetation health from satellite imagery. NDVI is a widely used remote sensing index that distinguishes healthy, dense vegetation from sparse vegetation or impervious surfaces based on how surfaces reflect visible and infrared light. The resulting map highlights clear contrast between agricultural land, green space, and the built environment, demonstrating how a simple spectral index can communicate environmental information effectively to a non-specialist audience such as urban planners or conservation researchers.

Project Overview

This project compares three approaches to classifying land cover from Sentinel satellite imagery of Science Park, Utrecht: unsupervised pixel-based, unsupervised object-based, and supervised pixel-based classification. The goal was to evaluate how the choice of classification method affects the accuracy and interpretability of land cover maps used in environmental monitoring. Each method distinguishes categories such as water, urban, agriculture, and open field, but with notably different levels of accuracy. The supervised approach, trained on hand-digitized samples, produced the most realistic and reliable result, while the unsupervised methods revealed common pitfalls, such as mislabeled clusters and spurious classes. This project demonstrates a practical understanding of how classification method choice directly affects map reliability for real-world environmental applications.

Methods

I used ArcGIS Pro to classify Sentinel satellite imagery of Science Park, Utrecht. After loading the multiband image and adjusting band combinations for visual interpretation, I measured pixel size with the measure tool and generated a spectral profile across multiple land cover types to compare their reflectance signatures. For the unsupervised classifications, I used the Image Classification Wizard to run both pixel-based and object-based clustering, allowing the algorithm to group pixels by spectral similarity before manually relabeling each cluster. For the supervised classification, I digitized training samples for each land cover class, generated a signature file using the Create Signatures tool, and classified the image using a Support Vector Machine. To calculate NDVI, I used the Raster Functions tool, selecting the appropriate visible and infrared bands and applying a green-to-orange color scheme to represent vegetation health. Accuracy assessment via a confusion matrix is planned using ground-truth points to compare classified results against known land cover values.
